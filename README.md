# 📈 Stock Market Sentiment Analysis using LSTM

Predict stock prices using **LSTM neural networks** with **news sentiment analysis**.

## Features
- Multi-brand stock selection (Apple, Google, Microsoft, Tesla)
- Real-time stock data (Yahoo Finance)
- News sentiment analysis
- LSTM-based prediction
- RMSE & MAE evaluation
- Prediction graph visualization

## How to Run
```bash
pip install -r requirements.txt
python main.py
